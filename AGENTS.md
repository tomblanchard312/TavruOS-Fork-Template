# Tavru repository rules

Every Tavru chat interface, including Oqelith, MUST follow [the chat interface standard](docs/chat-interface-standard.md). Read it before implementing or reviewing chat changes. Preserve these rules when adopting this template into a private product; link the adopted standard from that product's root AGENTS.md. Record acceptance evidence against rule IDs; do not claim ecosystem compliance without reviewing existing applications.

Keep public tracking forks free of private product code, credentials and restricted assets. Follow README.md and docs/security.md for repository boundaries.
